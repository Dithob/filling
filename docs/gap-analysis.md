# 真实投递页实测缺口清单（阶段 0 产出）

> 用法：用原版插件跑真实投递页，把问题按下面三类登记。这张表决定阶段 2~4 的优先级。
> 每测一个站点复制一份表格，站点名做小标题。

## 分类说明

| 类别 | 含义 | 对应阶段 |
|---|---|---|
| A 未识别 | 字段没被扫描到，或扫描到了但匹配不到 slot（侧边栏显示黄标） | 阶段 2 扩词典 |
| B 填不进 | 匹配正确，但点击填入后页面值没变（自定义下拉 / 富文本 / 日期 / 附件） | 阶段 3 填充器 |
| C 格式错 | 填进去了但格式不对（日期、学历枚举、城市、薪资） | 阶段 2 归一化 |
