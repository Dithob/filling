FieldBook Form Testbed

Hosted fixtures that mimic real-world applicant tracking system forms. Use this testbed with the FieldBook extension to validate field detection, autofill coverage, and instrumentation.

Scenarios

  • Simple baseline form
  • Messy form (missing labels)
  • Wizard (multi-step)
  • Array inputs (repeaters)
  • Address combinations
  • Segmented phone fields
  • File upload + cover letter
  • Shadow DOM variants
  • Same-origin iframe
  • Cross-origin iframe
  • Chinese labels

国内校招（二开）

  • 国内校招投递表单（含自检面板） — 中文标签 / 枚举下拉 / 附件 / 富文本 / Shadow DOM，右上角面板按 fixtures/sample-cn-profile.json 比对填入结果

用法：在扩展工作台导入 fixtures/sample-cn-profile.json，打开本页，点侧边栏「填写匹配字段」， 再回到页面看自检面板的通过率。

Usage

  1. Publish this folder via GitHub Pages (e.g., docs/ on main or gh-pages).
  2. Grant your extension host access to the published origin.
  3. Load the FieldBook extension and open one of the fixtures above.
  4. Use the Test Harness panel (top-right) to randomize DOM structure, load sample resume data, and diff expected vs. actual autofill values.
